# Nasijan - Premium Garment Identity & Accessories

Welcome to the Nasijan website repository. Nasijan is Egypt's premier manufacturer of garment accessories and brand identity solutions, partnering with fashion brands, clothing factories, and retail companies globally.

## 🌟 Project Overview

This is a modern, single-page, responsive, and bilingual (English/Arabic) website built with clean, vanilla web technologies. It is designed to reflect the premium quality of Nasijan's products through elegant typography, smooth micro-animations, and a refined color palette (Deep Navy, Copper/Gold, and Cream).

### ✨ Key Features
- **Bilingual Support (EN/AR):** Seamless switching between English (LTR) and Arabic (RTL) without page reloads.
- **Dark & Light Modes:** Built-in theme switcher that completely transforms the aesthetic while maintaining a premium feel.
- **Responsive Layout:** Fully optimized for mobile, tablet, and desktop devices.
- **Clean Architecture:** Organized file structure with zero external framework dependencies (Vanilla HTML, CSS, JS).
- **Interactive UI:** Features custom scrolling animations, animated counters, and floating particles for a dynamic user experience.

## 📂 Folder Structure

The project has been refactored into a clean code structure:

```text
Nasijan/
├── index.html                  # Main HTML document
├── README.md                   # Project documentation
└── assets/                     # Organized assets folder
    ├── css/
    │   └── style.css           # Global stylesheet (variables, layouts, animations)
    ├── js/
    │   ├── script.js           # Core interactivity and DOM manipulation
    │   └── translations.js     # Bilingual dictionary (English and Arabic copy)
    └── img/
        ├── Logo.png            # Primary brand logo
        ├── favicon.svg         # Vector favicon
        ├── Cover.png           # Hero/About section cover image
        └── img_*.jpg           # High-quality product gallery images
```

## 🛠️ Technology Stack
- **HTML5:** Semantic markup for accessibility and SEO.
- **CSS3:** Custom variables (`:root`), Flexbox/Grid layouts, and CSS animations.
- **JavaScript (ES6):** Modularized scripts for translation and state management (`localStorage` for theme and language preferences).
- **FontAwesome:** Scalable vector icons.
- **Google Fonts:** `Outfit` for English and `Cairo` for Arabic typography.

## 🚀 Getting Started

No build tools or servers are strictly required! To view the website locally:
1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.
3. Use the toggles in the top navigation bar to test Language and Theme switching.
